# system24-hyprland-amber

A custom preset for the system24 Discord theme, tailored for Hyprland, Foot, and Waybar.

## Features
- Palette: Dark Slate / Nord background (#111518, #1c2327) with warm amber and coral accents (#e3a857, #e05a47).
- Typography: JetBrainsMono Nerd Font.
- Tiling-Friendly: Hidden window controls.
- Round avatars and server icons.

## Installation
1. Download the theme file into ~/.config/Vencord/themes/:
   curl -fLo ~/.config/Vencord/themes/system24-hyprland.theme.css https://raw.githubusercontent.com/VanyaSloupok404/system24-hyprland-amber/main/system24-hyprland.theme.css
2. Enable system24-hyprland.theme.css in Vencord Settings -> Themes.
